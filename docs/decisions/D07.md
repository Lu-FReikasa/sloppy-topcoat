# D7 — No inference on the hub host

> **Status (2026-11-25):** Amended (the maintainer, 2026-11-25). The hub's own container never runs a model; models run only on nodes. A node may run on the same machine as the hub: a strong server with GPUs can be hub and model host at once. On a weak host (as on the maintainer's VM host) that node gets fixed RAM and CPU limits and small models only, such as the embedding model.

**Decision.** No inference on the hub host

**Why.** It has no GPU and little free RAM; it serves many people.
