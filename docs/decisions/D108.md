# D108 — An issue's investigation may try a guess, under the person's probe mandate

**Decision.** **The investigation of an issue ("Fix entwerfen") may write one small test file in the
workshop and run only that file, but only inside a probe mandate (D83) the person gives by a click on
the issue's card "Versuche erlauben".** The card shows the whole scope before the click; the hub fixes
it, never a model: the registered live repository, exactly the branch `topcoat/probe-<issue>`, one new
file `hub/tests/_probe_<n>.py` per try (named by the hub, at most 20 kB, no secret), the tests of that
one file (`repo.test_start` with `path`), no commit, no push, 24 hours or until revoked. After every
try the workshop goes back to `topcoat/live` with the change discarded. Amends D99 for this case
only: the file is confirmed by the scope, not one by one.

**Why.** Three investigations of issue 2.8 (2026-11-19) read the right function and never found the
cause; the reader guessed a type mismatch that does not exist, and the lead took it. One small test of
the real code would have shown both the cause and that the guess was wrong. Reading cannot refute a
guess; running can. Confirming each test file by hand would make the investigation wait on the person
for every guess, which defeats its purpose; an unbounded permission is not acceptable either (D83).

**How it is built.** `issue_probes.py` (the runner and the checks), `issue_investigation.py` (a
question to `"try"` is offered only while the mandate is active), `api/mandates.py`
(`POST /nodes/{issue}/probe-mandate`, the signed-in admin only, not an API key), the mandate action
`probe` (`project_mandates.ACTIONS`; an order's release still gives only `ORDER_ACTIONS`). On the
node, `repo.test_start` takes an optional `path`: one relative `.py` file, never an option, never
outside the copy, pytest template only.

**Checks on every try** (never waived by the mandate): an active probe mandate for exactly this
branch, the file name and size, no secret (`releases.mask_secrets`), a clean workshop. Every try is a
line of the project's Akte (`mandate.used`).

**Not decided here.** Tries that need the network, files outside `hub/tests/`, or other repositories.
