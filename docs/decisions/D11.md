# D11 — TLS from the start

**Decision.** TLS from the start. Hub modes: `auto` (hub-managed CA + server certificate), `files` (admin-provided certificate, e.g. from an internal CA), `off` (only behind a TLS-terminating reverse proxy, or tests). Nodes pin the hub CA fingerprint shown in the pairing command, or use the system/admin-provided trust store

**Why.** Admin token, node identities and later secrets (HF token, API keys) must never cross the LAN in clear text. Pinning needs no public CA and no manual trust setup on nodes.
