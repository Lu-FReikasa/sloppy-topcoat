# D114 — Images of themes and personas are hub files

> **Status (2026-11-25):** Decided by the maintainer (plan of 2026-11-24, recommendation 7). Not built: milestone *P6 Images*.

**Decision.** Backgrounds, sprite sheets, avatar figures and other images of a theme or a persona are stored by the hub as **asset files**, one set per version of the theme or persona, and referenced by id (for example `asset:<id>` in theme CSS, resolved by the hub to its own URL). Every asset is checked when it is stored: allowed types PNG, WebP and GIF; the image is decoded and encoded again (no metadata, no foreign payload); size and pixel limits per file and per theme; no remote URL. Assets belong to the theme or persona and go with it (versions, rollback, removal through the registry, [D105](D105.md)). Generated images ([D126](D126.md)) become assets the same way.

**Why.** Inline `data:image` within 40,000 characters of CSS is too small for an animated background or a sprite sheet, and a URL to the outside would load content the hub did not check. Re-encoding makes an image only an image.
