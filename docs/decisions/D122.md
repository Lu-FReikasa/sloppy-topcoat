# D122 — The repository is public before version 1.0

> **Status (2026-11-25):** Done. Replaces [D93](D93.md).

**Decision.** The repository `sloppy-topcoat` is public on GitHub (AGPL-3.0) from 2026-11-25, before version 1.0. It was started with a fresh history: one commit with the state of that day. The earlier history, branches and pull requests stay in a private archive repository. Plans, hand-overs and measurements live outside the repository; reference docs and decisions stay in it. Contributors work on branches and pull requests against `main` and follow `CLAUDE.md`; open tasks are GitHub issues.

**Why.** A second developer wants to help, and a public repository makes that simple; public repositories also get GitHub's CI runners. The old history held real host names, the maintainer's real name and mail domain in the commit metadata, and the removed hand-overs. Rewriting it would not have been enough, because GitHub keeps the head of every pull request (`refs/pull/*`) reachable, so a fresh repository was the only clean way.

**Consequences.** Everything that is pushed is public at once: the rules of `CLAUDE.md` (no real host names, addresses, user names or secrets) are now enforced by exposure, not only by habit. Commits use the GitHub noreply address. What the CI publishes on a merge to `main` is public too (see the open question in [D13](D13.md)).
