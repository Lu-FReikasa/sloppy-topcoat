# D13 — Release channels

> **Status (2026-11-25):** Under review. The practice differs: hub releases are images built with `scripts/dev/release.sh`, node builds are signed bundles served by the hub ([D50](D50.md), [D80](D80.md)), and version tags for a `prod` channel were never used. Since the repository is public ([D122](D122.md)), the CI job `publish channel test` publishes unsigned node binaries and the hub image publicly on every merge to `main`. Decide whether that job stays.

**Decision.** Release channels: every push to `main` publishes channel **test** (hub image tag `:test`, node binaries in the `test` pre-release); version tags `vX.Y.Z` will publish channel **prod**

**Why.** Try changes on real machines without a manual build; a stable channel exists once the first test passed.
