# D15 — The assistant only reads without explicit confirmation

**Decision.** The AI assistant may only **read** without an explicit user confirmation. Every state-changing action it proposes (on nodes, containers, models, users, configs, client devices …) is shown with its exact effect and executes only after the user confirms **that single action**; no blanket or session-wide approvals, no confirmation by the AI itself or by content it read. Confirmed and refused actions are audited with user and time.

**Why.** The assistant is central to the product and will act on many machines; prompt injection or a wrong conclusion must never change state on its own. Binding for stage 3 and everything after.
