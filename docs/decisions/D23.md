# D23 — Roles instead of device names

> **Status (2026-11-25):** Replaced by [D78](D78.md), then [D85](D85.md), [D115](D115.md) and [D117](D117.md).

**Decision.** **Roles instead of device names.** A node (and, more finely, a model on it) serves the roles `fast` (the first answer of a chat) and `deep` (thorough background work: memory extraction and consolidation, clarification, later research and verification). Config: `config.work = {roles, model_roles}`; a node without the field serves both, so nothing changes until an admin sets it. The hub picks a machine by role, availability (`available`, `paused`, `offline`; `busy_gaming` and `yielded` count as unavailable) and benchmark values (pp/tg); **no code or setting names a device**. `fast` requests never wait for a `deep` node. The gaming PC is not planned in the basic setup and may join later as an extra `deep` or `fast` machine through the same roles.

**Why.** Measured on the real machines: the GPU machine answers in a fraction of a second, the low-power laptop is 10–15× slower but can run a much better 30B model on the CPU overnight. Roles let both do what they are good at without the code knowing which is which.
