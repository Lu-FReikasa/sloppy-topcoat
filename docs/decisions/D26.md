# D26 — Follow-up checks of an answer

**Decision.** **Follow-up checks of an answer** by a deep node appear as **their own message** under the answer, ranked `red` (warning, a fundamental problem: the answer was wrong or dangerously misleading), `yellow` (a more precise description, important extra context or a small correction) or `green` (confirmed). The model proposes rank and reason; the hub validates: a known rank, a non-empty reason, and for `red` a concrete claim quoted from the answer — otherwise the rank drops to `yellow`. Red follow-ups also mark the conversation in the list. Per user; the check reads only that user's conversation (and memory, D20).

**Why.** The quick model answers first and may be wrong; a slower, better model can check afterwards without making the user wait — but its verdict must be visible, ranked, and hard to abuse (a model crying wolf on every answer would be ignored).
