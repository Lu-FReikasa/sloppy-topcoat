# D33 — Escalation to an external LLM (removed)

**Decision.** **Removed (consolidation step 6, decided by the maintainer): the hub has no code that calls an external model.** The escalation of a diagnosis or an answer to an external LLM (redaction, approval per request, budget) was built and then dropped; its tables and settings are gone (migration 0074). It is not planned. A future external call would need a new decision first and would have to go through `redaction.py`.

**Why.** Local-only is the product: nothing about the home lab leaves it. The redaction layer stays because the web capabilities (D35), the hand-over and the self tool use its detection.
