# D36 — The internet is a switch of its own in the chat, not one of the tool groups

**Decision.** **The internet is a switch of its own in the chat, not one of the tool groups (E3-04).** Per conversation (default: a user setting), independent of the servers and groups chosen: deselecting every server leaves web search in place, switching the internet off removes only the web. The web capabilities come from **one** node the hub picks among those released to the user (D20 grants) — the model never chooses between nodes for the web, and a search node needs not be one of the servers the user selected. Off is said to the assistant ("Internet is switched off here") so it points to the switch instead of claiming it cannot search; the panel shows *Internet: on (via node) / off*. The switch only ever narrows, like the rest of the scope, and the private-data guard of D35 applies unchanged.

**Why.** Searching the web is a different decision from letting the assistant look at one's servers: one is about privacy of the query, the other about access to machines. Tied together (as the web group was) a user who wanted only the servers lost the web by accident, or kept it by accident when narrowing the servers.
