# D42 — Honesty by mechanism, not by prompt

**Decision.** **Honesty by mechanism, not by prompt (E3-07 D4).** (a) *Noting.* The model does not promise to have noted anything (the prompt says so, and `chat.claims_noted` finds the promise anyway); what is true is shown by the hub: `Gemerkt: …` from the real write result, or `Nicht gemerkt, weil …` with a reason code (`secret`, `no_statement`, `too_long`, `nothing_found`, `memory_off`, `pending`, `failed`) in the `memory` event's `not_noted`. When the user says *notiere das* / *merk dir …* (`memory.explicit_request`), the sentence they want noted is cut out of their message and given to the memory model as an instruction; whatever the model made of it (nothing, a non-JSON answer, a paraphrase that lost the meaning, a note flagged *volatile* that would vanish in 24 h) the hub then notes the user's own sentence itself (`_note_as_asked`: kind by its words, durable, through the secret filter, evidence `doc` — the user said it outright), or says why it cannot. (b) *A finding holds for the node that gave it.* The agent's diagnosis records a *coverage* (`asked`: nodes that returned evidence; `not_asked`: nodes the task could have asked and did not; the notes and the web are no nodes); a claim that something is absent (`chat.says_nothing_exists`) is rewritten by the hub to *… — nur auf X geprüft; nicht geprüft: Y*, the closing bubble cannot say it without that (`chat.guard_scope` replaces the sentence), the card shows the coverage, and the model that writes the bubble is told *NOT asked: Y*. For a question about a service (*Läuft Plex?*) the agent's first message names `kuma.monitors` and `knowledge.search` (as far as they exist) to be asked before single machines. (c) *Loops.* Chat requests carry `repeat_penalty` for model families that need it (built in: `gemma` 1.1; `TOPCOAT_CHAT_SAMPLING` changes or removes it, by family, longest match wins).

**Why.** The assistant said *ich habe das notiert* when nothing had been written, said *Plex gibt es nicht* after looking at one of several machines, and fell into *die Lage Lage Lage* with gemma. Each is a statement a model makes freely; each has a fact in the hub that decides it (the write result, the list of nodes asked, the sampling the request was sent with). The reply is made from the fact, not from the model's promise. The value `1.1` is an assumption (test plan measures it); everything else is deterministic and tested.

**Extended (AGT-01, 2026-10-30).** The same rule for changes: when the closing answer of a check says that something was changed or is ready to confirm, the hub holds it against its record and writes the true state under it (`claims.py`, HUB-API "Honesty by mechanism").
