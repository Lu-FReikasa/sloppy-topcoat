# D48 — The assistant may learn rules and styles itself, in a narrow way

**Decision.** **The assistant may learn rules and styles itself, in a narrow way (changes D38 on the owner's explicit wish).** When the user says in a conversation how answers should be given, the memory step writes the rule or style itself (`MemoryStore.learn_instruction`, actor and `source_type` `agent`) instead of queuing a proposal, if (a) the quote is the user's own words in that very message, (b) it does not relax a confirmation, approval or write right (`core_rules.loosens_safety`; such a rule stays a proposal for a click), (c) it is new and was not rejected before, (d) fewer than 20 learned ones are active. It is marked as learned on the Instructions page, is a normal versioned note, and one click removes or reverts it. Text from the web, a tool or a note file never writes one. `TOPCOAT_MEMORY_AGENT_LEARNS=false` switches it off. Facts and pointers are stored more generously (up to 8 per turn); the existing consolidation run tidies afterwards.

**Why.** The user wants the assistant to build its own knowledge base and adapt within a conversation; unlimited self-written rules would be a prompt-injection and drift risk, so scope, marking and undo are the safeguards.
