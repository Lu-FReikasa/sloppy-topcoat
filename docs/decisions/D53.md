# D53 — Sections, incognito and a short tool list in the chat

> **Status (2026-11-25):** Replaced by [D54](D54.md) and [D77](D77.md). The cut inside one chat remains only for chats from before.

**Decision.** **Sections, incognito and a short tool list in the chat (user area).** A conversation is one history for the person and several *sections* for the model: a rest of `segment_idle_seconds` ends one, and so does the person's "new section" (`POST /api/conversations/{id}/segments/break`, a timestamp in `conversations.segment_breaks`, migration 0049; nothing is deleted, the closed section is summarised and handed over like after a rest). The tool scope (D36) gets `memory: false` = **incognito**: the assistant uses no server, no tool group and no notes in that conversation and keeps nothing about the person (the hub removes every capability but the web search; the internet switch decides over that); it can only switch the person's setting off, never on, and it is not carried over to the next conversation. The notes (knowledge base) are a hub view like Topcoat and GitHub: choosing servers never removes them, only the group switch or incognito does. A chat check whose question names an unmistakable topic (container, journal, Omada, Uptime Kuma, DNS/ports/certificates, Keycloak, GitHub, workshop) is offered only that topic's tool groups plus Topcoat, notes and host facts (`TOPCOAT_AGENT_AUTO_TOOL_GROUPS`, default on; a question without a topic or a choice of groups by the person keeps everything); the run's first step says so, and the size of the tool definitions is logged once per run. `GET /api/chat/tools` also says where each group runs (`hub`, `node`) and which capabilities each server offers per group, so the window can show what the assistant may do on which server.

**Why.** Small models read every tool definition on every turn: a shorter list leaves room for the answer and gives fewer wrong calls, but taking tools away on a guess would cost answers, so only a clear topic narrows and the note tells the person. Incognito and sections are the person's levers over what the assistant knows, and both only ever reduce it.
