# D55 — One way to connect a repository

**Decision.** **One way to connect a repository.** The hub setting for GitHub (`TOPCOAT_GITHUB_REPO` / `TOPCOAT_GITHUB_TOKEN`) is removed: every repository, the assistant's code reading and the dev workshop alike, is registered on the Repositories page with its own token and mode.

**Why.** Two ways meant two sources of error: a repository set in the environment was invisible on the page, listed twice when it was also registered, and the assistant took the duplicate for a second repository.
