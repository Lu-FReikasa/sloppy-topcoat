# D57 — Announced, not done

**Decision.** **Announced, not done (E7-02).** A model sometimes ends its turn on "I will look at that now". ``promise.py`` finds that case by mechanism, like ``claims_noted`` finds a false "noted" (D42): it reads only the *end* of a finished answer that used no tool and names the sentence that announces an action. The answer is then shown as what it is — an item "announced, not done" in the chain and a button that asks for it to be done now — and not as a complete answer. The detector is narrow: an offer ("shall I look?"), a question, a past tense or an announcement that the answer goes on to carry out are not flagged; a missed case costs nothing, a wrong flag costs a warning under a good answer.

**Why.** The prompt cannot make a small model keep a promise; the hub can at least refuse to call a broken one finished.
