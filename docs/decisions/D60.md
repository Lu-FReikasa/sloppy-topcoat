# D60 — The interface is data drawn by a shell

> **Status (2026-11-25):** Replaced in part. Layout documents are removed by [D70](D70.md); workspaces, templates and profiles remain; views and plug-ins are [D105](D105.md).

**Decision.** **The interface is data drawn by a shell (L1–L5; the tile and desk shells were replaced by the desktop, D70; the layout plan is in the git history).** A *module* is code in the web build; a *window* is an instance of it in a *layout document* the hub stores per person, workspace and shell (`ui_layouts`, JSONB, checked against `proto/ui/layout.schema.json` and by code, at most 64 KiB, 24 windows, depth 12, one placement per shell so that switching shells loses nothing); a *workspace* (`ui_templates`, owned by `SYSTEM_ID`) names modules **and** the agent's defaults (tool scope, answer path, persona, model role) as defaults for new conversations; a person's *prefs* (shell, mode, theme) are clamped data, a theme never code. Layouts, grants and templates reach open pages as events on the stream (`ui_layout` for one person, `ui_access` for all); no web build is needed to change them. **Rights only narrow:** a profile allows workspaces (off unless allowed) and denies tool groups (on unless denied), deny wins; the admin role ignores profiles; the effective tools of a workspace are its defaults minus what the profile denies, on top of the per-person grants of D20 which stay the gate of every call; a workspace a person may not open is `404`; a module that needs the admin role or a denied group cannot be added to a layout; a profile or workspace can be `locked`. The agent may **propose** a window action and the person applies it with one click (D15, D43); nothing applies itself.

**Why.** One chat with an admin console behind it does not fit a household that also writes mail, plays music and edits photos, and a hard-coded menu cannot be switched off for one person. Data, not code, is what lets an admin shape it while the hub runs; the shell is the only part with an opinion about look and feel.
