# D62 — Memory belongs to an application or is shared

**Decision.** **Memory belongs to an application or is shared (P2).** A note is shared (``application`` null: about the person, seen in every application) or belongs to one application. What is about the person (person, preference, style, rule) is shared; operational notes and episodes belong to the application of the conversation they were learned in. Recall, the core block of a conversation and the background reviews read through a scope: the shared notes minus the person's denied tags, and the application's own, never another application's. The person's tags hide a shared note from the applications it was not released for (``private``, ``health``, ``finance`` by default; ``user_settings.memory_tag_rules``). The memory page has a tab per application and shows the episodes that had no page; the person moves a note and tags it; notes learned before applications existed are sorted by a suggestion from their words that the person accepts in one go, never silently. The notes of the Dev application go stale after a week (``memory_halflife_dev_days``).

**Why.** The dev topic had no home (45 of about 70 dev-related notes in the export were episodes, aging like small talk), and one memory for everything lets Chat know what only Admin should. The boundary is in the data, so it holds for later users too.
