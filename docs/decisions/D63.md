# D63 — The incognito folder

**Decision.** **The incognito folder (section 3.9 of docs/PLATFORM.md).** A conversation that exists only in the memory of the hub: its own generic system prompt, no memory, notes, wiki, servers or tools but the web (search and reading a page, switchable per tab), no row of any kind (no conversation, message, note, task, audit row or inbox item), nothing learned. ``ToolService.invoke(unrecorded=True)`` leaves no audit row whatever the outcome; private data in a query is still refused. Tabs stay until the person burns them or the hub restarts, within limits (20 tabs, 200 messages each). The claim is "never written", not "deleted afterwards" (a deleted row lives on in the database, its log and its backups), and it is proven by a test: a whole turn, web search included, leaves no new row in any table and the question stands in no log line. The window says what it does not hide (a web search leaves the hub, a model machine keeps the prompt in its working memory).

**Why.** Deleting is not forgetting: the only reliable way to leave no trace in the hub is not to write one.
