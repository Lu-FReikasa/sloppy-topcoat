# D66 — Effort is a variable of the run

> **Status (2026-11-25):** Amended. Since the flows are gone ([D115](D115.md)) the effort tables live in the setting document `chat_policy` (`chat_policy.py`); the `second_look` node is gone ([D26](D26.md)).

**Decision.** **Effort is a variable of the run (section 3.6 of docs/PLATFORM.md).** A run carries an effort (``fast``, ``balanced``, ``thorough``; ``{{effort}}`` in templates). Any parameter of a node may hold an *effort table* ``{"effort": {level: value}}`` instead of one value; the engine reads the value of the run's level when the node starts (a missing level uses the balanced one), every value is checked like the parameter itself, and the editor shows one field per level. Every node has ``enabled`` (a table too): off at this effort it takes no time and hands on what it was given (state ``skipped``). New: the ``second_look`` node (another model marks what the evidence does not show, the answer goes on unchanged; off unless careful), ``reasoning`` on the ``llm`` node (``reasoning_effort``), and the ``agent`` node follows the run's effort unless its ``quality`` is fixed. The level no longer picks a model: the answer comes from the picked or default model; only the second look has one (``thorough`` of ``chat_quality_models``).

**Why.** Tuning "how careful is careful" must not need a release, and one coupling of level to model made two decisions out of one. Policy nodes that need the chat answer as a flow (Placement, Limits, Recall, Write memory) wait for that flow.
