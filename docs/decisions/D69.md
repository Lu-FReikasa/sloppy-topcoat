# D69 — The tools of an application are a ceiling

**Decision.** **The tools of an application are a ceiling (app_scope.py).** What an application's workspace allows, narrowed by the profile, is the most a conversation of that application may use; the hub cuts the conversation's own choice down to it where a turn's scope is settled, and the picker (`GET /api/chat/tools?application=`) offers only those groups. Built-in ceilings: Chat and Research the notes (wiki) and the web, Development the workshop and GitHub without the web, Administration the server groups. Conversations from before applications were given to Chat (migration 0063); a conversation opened through the API without an application has only the person's grants as its limit.

**Why.** One shared tool list made the applications look separate while they were not; what an application cannot do it asks of another by a hand-over.
