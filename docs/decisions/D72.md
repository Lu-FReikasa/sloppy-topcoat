# D72 — The chat model may propose a hand-over

**Decision.** **The chat model may propose a hand-over.** In a conversation of a program, a model that makes native calls is offered `hand_over` next to `look_at_my_systems`, with the person's other programs that have tools as its targets and what each can do. Calling it prepares the dossier (`proposed`), the answer says where it is, and the page opens it in the inbox under Hand-overs: nothing is sent before the person clicks Send (D15, D65). A target the model made up prepares nothing; conversations opened through the API without a program are not offered it.

**Why.** Chat and Research have no server tools any more (D69): the model must be able to say "that is Administration's" and set it up, without ever sending on its own.
