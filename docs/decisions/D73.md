# D73 — A second look

> **Status (2026-11-25):** Replaced. The look is a theme key ([docs/THEMES.md](../THEMES.md)); Leitstand is one of the built-in themes.

**Decision.** **A second look: the control room (Leitstand).** `ui_prefs.look` is `terminal` or `leitstand`; it is pure CSS on the desktop's root (`dt-look-*`, `web/src/desktop/leitstand.css`) plus three small parts the terminal hides (the lamp, the page code, the UTC clock). Colour carries meaning only: green normal, cyan selection, amber attention, red warning; the hue tints the housing. The taskbar lights the inbox amber (unread) or red (urgent) from `/api/inbox/counts`.

**Why.** The person asked for a third design after the themes were removed (D70). One extra look as a CSS layer keeps the one desktop and one set of components; the signal logic gives the look a purpose beyond decoration.
