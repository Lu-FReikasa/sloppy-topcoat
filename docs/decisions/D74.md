# D74 — A memory per program, a tag tree, a frame per program

**Decision.** **A memory per program, a tag tree, a frame per program, a cross-check by responsibility.** Each program (Chat, Research, Development, Administration) keeps its own memory (`memory_items.application`); the core (`application` null: person, preference, style, rule) is read by all; `operational` and `episode` never go to the core. Tags are rows (`memory_item_tags`) of one tree per person (`memory_tags`, `memory_tags.py`) with a fixed top level; `responsible`, `sensitive` and `released` are inherited down a branch. The extraction shows the model the tree and lets it add a tag only below a known one (two per note at most, marked unreviewed). Recall adds the notes below a tag the question names. The consolidation never crosses memories; the cross-check (`memory_check.py`, in the care run) reports a contradiction between two memories to the program responsible for its deepest tag (`memory_reports`), which decides in its frame and may send the other program a notice; a topic of the person or a sensitive one is a question to the person. A program's frame (`agent.frame`: tone and rules) stands in the core block after the system rules.

**Why.** The maintainer wants specialised programs with careful, separate contexts, a consensus where they overlap, and the program that knows a topic to settle it — Administration, not Chat, decides what a server does. Replaces the shared set and the deny / allow tag rules of PLATFORM.md 6.
