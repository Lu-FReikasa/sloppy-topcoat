# D82 — A reviewed result becomes part of the Project's Akte

**Decision.** **A reviewed result becomes part of the Project's Akte (changes PLATFORM 3.8 for the Project application).** A result of another application (Research, Development, Administration) is stored in the receiving project as a dated, sourced report (`as_of`, origin, `current`/`supersedes_id`); facts are superseded, never overwritten. It enters the Project agent's context through the digest and the tools only **after** the code verified it (schema, literal quotes against the stored evidence, source and host counts, stripped markup) and a restricted reviewer run submitted a verdict. The structural guard stays: raw text from a foreign source never reaches an agent that has write tools before that review; the reviewer can submit a verdict and nothing else; automatic runs only *prepare* change sets. Chat, Incognito and the hand-over of PLATFORM 3.8/3.9 are unchanged.

**Why.** A plan needs what was found out, with date and source, to stay in the project; the guard must not depend on a model being careful.
