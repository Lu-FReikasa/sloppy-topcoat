# D84 — The review loop has no hard limit, and its load is observed

**Decision.** **The review loop has no hard limit, and its load is observed.** The Project agent checks every delivered result against the expected behaviour and, if it falls short, starts another round (other questions, other sources) or orders a fix, as often as needed. Every message records its `stats`; at round 4 or a message running longer than 30 minutes (settings) the chain is *flagged* in the UI and in the project digest. Nothing is stopped by a flag; a chain can be stopped by the person at any time, and a stop takes effect for everything not yet sent.

**Why.** A fixed cap would end good work early; observation tells the maintainer when a chain runs away without deciding for them.
