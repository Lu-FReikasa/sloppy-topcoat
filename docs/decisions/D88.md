# D88 — One machine is a full setup

**Decision.** **One machine is a full setup; several are recommended (extends SPEC goals; built in part by SCH-02: a check runs on a one-model machine; chains and queue not built, SCHEDULING section 6).** Hub and a single node with one model and one slot must run every chain, including checks, one job after the other. A check waits for a quiet chat when its node has no free slot. Tests cover the one-node case for every chain, and defaults and documents do not assume a second machine.

**Why.** The system must be useful without a large home lab. The queue makes this nearly free: one node is the smallest case of the same rule, not a special mode.
