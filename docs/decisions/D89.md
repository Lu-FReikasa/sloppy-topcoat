# D89 — The agent may read the host thoroughly, and reads files only from folders named per node

**Decision.** **The agent may read the host thoroughly, and reads files only from folders named per node (changes INSTALL-NODE section 10; built in tasks/HOST-01, tested on fakes and on Linux, **UNVERIFIED on real Windows**; setup in INSTALL-NODE 10a).** New capability for reading files and listing folders, with validated paths inside an allow-list per node, a size limit and the secret mask. On Windows the fixed scripts stay and there is still no free shell; on Linux `shell.read` stays. User profiles stay closed unless a folder is added on purpose. Changing anything on a host stays out of scope.

**Why.** Troubleshooting a PC needs logs and configuration files, and the fixed scripts cannot read those. An allow-list keeps the promise that nothing a caller writes is executed, and the person decides what is visible, because reading can expose more than changing can damage.
