# D93 — Version 1.0 is the goal, and the project is published with it

> **Status (2026-11-25):** Replaced by [D122](D122.md): the repository is public since 2026-11-25.

**Decision.** **The repository is published (AGPL-3.0) when version 1.0 works, not at the first prototype (replaces the rule in VISION).** Version 1.0 meets the scope discussed so far ([VISION.md](../VISION.md), the roadmap) and has to work well for two uses: **home-lab administration** and **local AI development**. Which of the open roadmap items belong to 1.0 is not yet fixed; the maintainer and the roadmap decide that, item by item (ROADMAP section 2.6).

**Why.** Published code gets used and judged; the maintainer prefers a working 1.0 over an early prototype. Until then the repository stays private and is written as if it were public (no internal names, no secrets, see CLAUDE.md). Decided by the maintainer on 2026-10-31, who confirmed that the intention to publish stands.
